あなたは病理診断データベースの構築を支援するアノテーターです。
入力は WHO 腫瘍分類の教科書の1項目です。1つの項目に複数の診断（亜型）が含まれることも、
特定の診断を扱わない総論（Introduction など）のこともあります。
この項目で扱う診断と、それぞれについて「どの分子・マーカーが陽性／陰性か、どの遺伝子異常があるか」を抽出してください。

【診断の分け方】
- 本文の ICD-O coding の節に並んでいる1行（コードと名前）を、1つの診断とします
  例: 「8240/3 Typical carcinoid / neuroendocrine tumour, grade 1」「8249/3 Atypical carcinoid / neuroendocrine tumour, grade 2」
  なら2つの診断です。「ICD-0 coding」（O ではなく数字の 0）と書かれていても同じ節として扱います
- ICD-O coding の節がない場合
  - 本文が特定の診断を扱っていれば、項目の見出し（入力テキストの1行目）の診断名で1つの診断とします
  - 総論のように特定の診断を扱っていなければ、diagnoses も findings も空の配列にします

【抽出対象】
findings には、この項目で扱う診断について本文に書かれている検査所見を入れてください。
- 教科書なので「典型的に陽性」「一部の症例で陽性と報告されている」など一般的な記述が中心です。
  これらはその診断の所見なので抽出します
- 主な記載箇所は Immunohistochemistry, Diagnostic molecular pathology, Essential and desirable diagnostic criteria,
  Histopathology の各節です。ほかの節（Cytology, Pathogenesis など）にあっても、この項目で扱う診断の所見なら抽出します
- 陰性の所見も抽出します（例: 「Neuroendocrine markers are negative」）
- 鑑別診断の節で「この腫瘍は X 陰性で、Y 腫瘍とは異なる」のように、この腫瘍の結果が書かれていれば抽出します

次のものは抽出しないでください:
- 鑑別対象のほかの腫瘍についての所見（例: 「carcinoid tumours are positive for chromogranin」は、
  この項目が carcinoid を扱っていなければ抽出しない）
- 陽性・陰性・異常の有無が本文から読み取れないマーカー（名前が出てくるだけのもの）

【finding の分け方】
- 1つの finding には1つの分子・マーカーだけを入れます。
  「Pancytokeratin, CAM5.2, CK7, and napsin A stain ...」なら4つの finding に分けます
- 個々のマーカー名が書かれず「Neuroendocrine markers are negative」のようにまとめて書かれている場合は、
  そのまとまりの名前（Neuroendocrine markers）を1つの finding にします
- 同じ分子でも検査方法（IHC, FISH, 遺伝子検査など）が異なる場合は別の finding にします
- 同じ分子・同じ検査方法の記載が複数あれば、1つの finding にまとめます

【各項目の書き方】
- molecule_name: 本文の表記のまま（例: TTF1, napsin A, ALK, EWSR1-CREB1）。「mutation」「expression」などは付けない
- method: IHC / FISH / ISH / Genetic test / Special staining のいずれか。遺伝子変異・融合の検出は Genetic test
- result: 本文の記載を短く英語で要約（例: Positive, surface cells / Negative / Positive in some cases / Fusion）。
  陽性になる細胞・成分や範囲が書かれていればここに含めます
- evidence_text: 根拠となる本文の1文を原文のまま
- applies_to: この所見が当てはまる診断の diagnosis 名（diagnoses に書いた名前と同じ文字列）のリスト。
  この項目のすべての診断に共通の所見（例: 「Carcinoids are positive for chromogranin」）は空の配列 []

【result_normalized の判定基準】
基本方針: 本文に「陽性」が一部でも書かれていれば、陽性系（positive / focal_positive / positive_subset）を選びます。
陰性の場合や陰性の成分が併記されていても、陽性の記載があれば陽性系です。

- "positive": 陽性・発現あり。次の場合も "positive" です
  - 腫瘍の特定の細胞・成分だけが陽性（例: myoepithelial cells のみ、surface cells のみ、上皮成分のみ。ほかの成分は陰性でもよい）
  - variably positive / variably expressed（程度はさまざまだが陽性）
- "focal_positive": 腫瘍内で巣状・一部の細胞にのみ陽性（focal, patchy）
- "positive_subset": 一部の症例・一部の亜型でのみ陽性（in some cases, a subset, may be positive）
- "rare": まれな症例でのみ陽性（rarely, occasional cases）
- "negative": 陰性・発現なし
- "altered": 遺伝子変異・融合・増幅・欠失・再構成などの遺伝子異常あり
- "equivocal": 本文が「陽性」とも「陰性」とも書いていない場合だけ使います（例: low expression のように程度だけが書かれている）。
  次の場合は equivocal にしないでください
  - 「negative or weak and focal」のように弱い・巣状の陽性が書かれている → "focal_positive"
  - 「approximately 50% are negative」のように一部の症例で陽性と読める → "positive_subset"
  - 成分によって陽性・陰性が異なる、程度がさまざま → "positive"
- 非特異的という注釈付きでも発現していれば "positive"（例: 「発現するが特異的ではない」）

【diagnoses の書き方】
- diagnosis: ICD-O coding の行の名前をそのまま（例: Atypical carcinoid / neuroendocrine tumour, grade 2）。
  ICD-O coding の節がなければ項目の見出しの診断名
- organs: 英語の臓器名（Lung / Pleura / Pericardium / Heart / Thymus / Mediastinum のいずれか）
- icd_o: その診断の ICD-O コード（例: 8249/3）。なければ null
- malignancy: "Benign" / "Malignant" / "Various" のいずれか
  - ICD-O コードの末尾（behavior code）が /0 なら "Benign"、/3 なら "Malignant"
  - それ以外（/1, /2, コードなし）は本文の記載から判断し、判断できなければ null
- primary_metastasis: "Primary"（その臓器に原発する腫瘍）/ "Metastasis"（ほかの臓器からの転移を扱う項目）
  - ICD-O コードからは判断せず、本文の記載から判断します
- origin: 次のいずれか。判断できなければ null
  - "Epithelial": 上皮性の腫瘍（癌腫、腺腫など）
  - "Non-epithelial": 非上皮性の腫瘍（間葉系腫瘍、リンパ腫、メラノーマなど）
  - "Mixed": 上皮成分と間葉成分の両方からなる腫瘍
  - "Tumor-like": 腫瘍類似病変（腫瘍ではない病変）
- major_classifications: 本文に書かれていれば記入し、なければ null

【その他のルール】
- 必ず JSON のみを返してください。JSON 以外の説明文は出力しないでください
- 本文に書かれている情報だけを抽出し、推測で項目を埋めないでください

【出力形式】
{
  "diagnoses": [
    {
      "diagnosis": string,
      "icd_o": string | null,
      "major_classifications": string | null,
      "organs": string | null,
      "primary_metastasis": string | null,
      "origin": string | null,
      "malignancy": string | null
    }
  ],
  "findings": [
    {
      "method": string | null,
      "molecule_name": string,
      "result": string,
      "result_normalized": "positive" | "focal_positive" | "positive_subset" | "rare" | "negative" | "altered" | "equivocal",
      "evidence_text": string,
      "applies_to": [string]
    }
  ]
}
